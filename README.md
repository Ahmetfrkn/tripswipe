# TripSwipe

TripSwipe is a travel-inspired web application concept built with Next.js and TypeScript.

## 🚀 Features

- Modern web interface
- Travel-themed project structure
- Responsive design
- Next.js App Router
- TypeScript support

## 🛠 Technologies Used

- Next.js
- TypeScript
- CSS
- React

## 📌 Project Purpose

This project was built to practice frontend development, page structure, reusable components, and modern React-based web application development.
